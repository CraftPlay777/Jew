# Jew Browser 1.2

Navegador Android basado en WebView y Java.

## Incluye
- Barra de navegación sin título de aplicación ni contador de pestañas.
- Campo de dirección con el marcador `Search/URL` en la pantalla de inicio.
- Vista de ventanas abiertas en tarjetas, con icono/favicon del sitio cuando está disponible.
- Accesos directos de inicio con favicon del dominio.
- Favoritos con estrella amarilla persistente y opción para quitar cada página.
- Historial con título y URL en filas separadas.
- Pantalla interna de descargas con progreso, abrir, compartir y cancelar/eliminar.
- Archivos guardados en la carpeta pública `Download/Downloads/Descargas` del dispositivo.
- Temas claro, oscuro y según el sistema.
- Buscador configurable: Google, DuckDuckGo o URL personalizada.

## Compilar
GitHub Actions: ejecutar `Build Jew APK` y descargar el artefacto `Jew-debug-apk`.

Paquete: `com.CraftPlay777.jew`
